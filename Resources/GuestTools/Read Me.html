MacVM Guest Tools

This package connects your macOS virtual machine to MacVM’s Shut Down button and optional text clipboard sharing.

  1. Sign in to the macOS virtual machine.
  2. Open Install MacVM Guest Tools.pkg in this folder.
  3. Follow the installer and enter the guest’s administrator password.
  4. Restart the guest using its Apple menu.

Requires macOS 26 or later inside an Apple silicon virtual machine. Install once per macOS guest. Linux guests do not need this package. The installer refuses to run on a physical Mac.

Preview status

Desktop and login-screen shutdown have been tested on macOS 27.0.1. If another user session exists, sign in before requesting shutdown so macOS can handle open applications. If MacVM cannot connect, use the guest’s own power menu. MacVM never automatically forces shutdown.

Updates and removal

To update, rerun the installer included with the newer MacVM app, then restart the guest.

To remove, run this command in the guest’s Terminal:

sudo "/Library/Application Support/MacVM/GuestTools/uninstall.sh"

How it works

The background helper accepts shutdown and optional text clipboard requests only from this VM’s host. No SSH access, network ports, or stored passwords are required. Applications can still ask you to save changes before shutting down.

Clipboard sharing starts disabled. Enable Share clipboard in MacVM’s Machine Settings while the machine is shut down. Update Guest Tools after updating MacVM. Text is shared only while this guest window is active.
