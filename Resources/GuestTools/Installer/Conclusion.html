Restart your virtual machine

Choose Apple menu → Restart inside this guest to finish setting up MacVM Guest Tools. You can then use MacVM’s Shut Down button.

To update, run the installer included with a newer MacVM version, then restart the guest again.

To remove Guest Tools, run this command in the guest’s Terminal:

sudo "/Library/Application Support/MacVM/GuestTools/uninstall.sh"

If shutdown is unavailable, use the guest’s Apple menu. MacVM never automatically forces a guest to power off.

Clipboard sharing starts disabled. Enable Share clipboard in MacVM’s Machine Settings while the machine is shut down. Update Guest Tools after updating MacVM. Text is shared only while this guest window is active.
