MacVM Guest Tools

Install this helper inside your macOS virtual machine to use MacVM’s Shut Down button.

Requires macOS 26 or later on an Apple silicon virtual machine. It cannot be installed on a physical Mac. Linux guests do not need it.

The helper runs in the background and accepts shutdown and optional text clipboard requests only from the virtual machine’s host. It does not enable Remote Login, open network ports, or store your password.

Preview: Desktop and login-screen shutdown have been tested on macOS 27.0.1. If another user session exists, sign in before shutting down. Use the guest’s power menu if MacVM cannot connect.

Clipboard sharing starts disabled. Enable Share clipboard in MacVM’s Machine Settings while the machine is shut down. Update Guest Tools after updating MacVM. Text is shared only while this guest window is active.
